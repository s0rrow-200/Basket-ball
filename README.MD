🏀 Basket Ball

🎮 Opis gry

Basket Ball to gra zręcznościowa. Zadaniem gracza jest trafienie piłką do kosza. Przeszkadza mu w tym bot!

👑 Zasady gry

1. Rzucaj piłką do kosza.
2. Za każde trafienie zdobywasz koronę 👑.
3. Po udanym trafieniu pojawia się komunikat VICTORY!.
4. Bot próbuje przeszkodzić Ci w zdobywaniu punktów.

⭐ Funkcje

- 🏀 Rzucanie piłką do kosza.
- 👑 Zdobywanie koron.
- 🏆 Komunikat VICTORY.
- 🤖 Bot utrudniający grę.
